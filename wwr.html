White Water Rafting Project

This project was developed as part of my WDD 130 course. The goal was to design and build a website for a white water rafting company.

Project Overview

In this project, I created a multi-page website using HTML and CSS. The site includes different sections such as a homepage, information about rafting trips, and contact details.

Skills Applied

  • HTML structure and semantic elements
  • CSS styling and layout
  • Page organization and navigation
  • Design consistency across multiple pages

What I Learned

This project helped me improve my ability to organize content, create clean layouts, and build user-friendly web pages. I also gained more confidence in using HTML and CSS together.

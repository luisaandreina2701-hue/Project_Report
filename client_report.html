Client / Developer Team Project Report

Client Report

As a client, I carefully created a clear site plan and chose images that matched the theme and purpose of the site. I wanted the site to feel organized, simple, and visually appealing.

I communicated with my lead developer through messages and shared feedback throughout the process. We had a few small delays in communication, but overall we were able to resolve issues by asking questions and clarifying expectations. I made sure to review the progress and provide suggestions when needed.

My developer met my expectations by creating a clean and functional website that followed my site plan. The layout, colors, and structure were consistent with what I had requested.

If I were to hire a team again, I would communicate more frequently and set clearer deadlines to improve efficiency and avoid delays.

Lead Developer Report

As a lead developer, I managed my team by organizing tasks and assigning each junior developer a specific page to complete. I provided clear instructions and expectations for layout, content, and design to ensure consistency across the website.

I communicated regularly with my client to ensure the project met their expectations. I shared updates and asked for feedback during development. When misunderstandings occurred, I clarified the requirements and made necessary changes.

I handled publishing the website using GitHub Pages. I created and managed the repository, gave access to my team members, and ensured all files were properly uploaded. After publishing, I shared the live link with the client for review.

Using GitHub was a valuable learning experience. I improved my skills in version control, managing repositories, and collaborating with others. I also learned how to troubleshoot issues related to uploading and updating files.

General Experience and Reflections

The most challenging part of this project was coordinating with multiple people and using GitHub effectively. However, I was able to overcome these challenges by improving my communication and practicing my technical skills.

What I enjoyed most about this project was working on real-world scenarios and collaborating with a team. It helped me understand how web development projects work in real life.

If I could do the project again, I would start earlier, communicate more consistently, and plan tasks more clearly to avoid last-minute stress.

This project helped me improve my HTML and CSS skills. I became more confident in structuring web pages, organizing content, and applying styles to create a clean design.

I also improved my teamwork and problem-solving skills by working with others, resolving misunderstandings, and adapting to challenges.

After this experience, I feel more confident working on real-world projects because I understand how to collaborate, manage tasks, and use GitHub to build and publish websites.
